# Электровэн — подбор электрического минивэна

Статический сайт без сборки: `index.html`, папка `assets` (стили и скрипт) и папка `img` (фото).
Работает на GitHub Pages, Netlify или просто при открытии `index.html` в браузере.

## Что внутри

- **Подбор** — ползунки приоритетов (цена, запас хода, зарядка, сервис, простор) пересчитывают рейтинг; фильтры «в бюджете» и «салон на 6 мест».
- **Карточка машины** — кнопка «Подробнее»: фото, все характеристики, цена, «Для вас» и «Учесть», источники.
- **Сравнение** — таблица по отмеченным машинам, лучшее значение помечено ★.
- **Утильсбор** — оценка ступени по пиковой или 30-минутной мощности.
- **Чек-лист поездки на втором ряду** — отметки сохраняются в браузере отдельно для каждой машины.

## Как выложить на GitHub Pages

1. Зайдите на github.com → **New repository**. Название, например, `minivan`. Тип — **Public** (на бесплатном тарифе Pages работает только для публичных репозиториев).
2. На странице нового репозитория нажмите **uploading an existing file**.
3. Перетащите в окно **содержимое** папки сайта: `index.html`, `README.md`, папки `assets` и `img`. Важно: `index.html` должен лежать в корне репозитория, а не внутри ещё одной папки.
4. Нажмите **Commit changes**.
5. Откройте **Settings → Pages**. В разделе **Build and deployment** выберите *Source: Deploy from a branch*, ветка **main**, папка **/ (root)** → **Save**.
6. Через 1–2 минуты сверху страницы Pages появится адрес вида `https://ВАШ-ЛОГИН.github.io/minivan/`. Это и есть сайт.

Обновить сайт: в репозитории **Add file → Upload files**, загрузите изменённые файлы с теми же именами → **Commit changes**. Через минуту изменения появятся.

## Как поменять данные

Все машины, цены и характеристики — в начале файла `assets/app.js`, массив `CARS`.

- Цена: `priceMin` и `priceMax` в млн ₽ (`null` — «по запросу»).
- Нет данных — ставьте `null`, на сайте появится «н/д».
- Фото: положите файл в `img/` и укажите путь в полях `ext` (общий вид) и `int` (салон).
- Пункты чек-листа — массив `CHECKLIST` там же.

## Важно

- Репозиторий публичный — сайт и фото увидит любой, у кого есть ссылка. Фото — пресс-материалы производителей; для личного использования это обычно нормально, для публичной рекламы — нет.
- Цены — ориентиры по сайтам импортёров и дилеров на 5 октября 2026, не оферты. Утильсбор — оценка, не расчёт таможни.
- Шрифты подгружаются с Google Fonts; без интернета сайт откроется с системным шрифтом.
